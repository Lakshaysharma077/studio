# **App Name**: Ksons Garage Door Services

## Core Features:

- Service Showcase: Showcase garage door services offered (installation, repair, emergency).
- Online Booking: Allow customers to book services through a form integrated with Stripe for payments.
- Contact Form: Enable customers to send inquiries and contact the business directly through a contact form. Data stored to MongoDB.
- Admin Dashboard: A hidden admin dashboard to view bookings and customer details. (Read-only access in v1)

## Style Guidelines:

- Primary color: Deep blue (#2245A3) to convey trust and reliability.
- Background color: Light gray (#F0F4F8), providing a clean and professional backdrop.
- Accent color: Bright orange (#FF8C00) to draw attention to CTAs like 'Book Now' and 'Get a Quote'.
- Body and headline font: 'PT Sans', a modern, readable, humanist sans-serif for all text.
- Use clear, service-related icons (e.g., a garage door, wrench, phone) to visually represent the services offered.
- Clean contractor-style layout with a strong hero section, prominent CTAs, and trust-focused content placement (services, reliability, location).
- Subtle transition animations on hover for buttons and interactive elements to enhance user experience.
